# 两位唐诗作者文本特征比较：王维 与 孟浩然

> 基于 TfidfVectorizer 的关键词对照 · 语料取自 [Lars-0317/chinse-poetry](https://github.com/Lars-0317/chinse-poetry/tree/master) · 生成日期 2026-11-19 · 样本 80 + 80 首五言律诗

> **结论速览：**在严格控制时期、流派、体裁与篇幅后，两组样本的用词分布仍有可测差异：王维的前列词集中在远景、登临与送别（白云、落日、行人、云外），孟浩然集中在交游、乡园与道流宴集（故人、乡园、神仙、征帆、知音）。但高权重词并非排他——「故人」「白云」在两组都出现；且换分词方案或换样本后，Top15 词表重合度仅 0.11～0.88。因此结论只宜作为细读线索，而非作者风格的定论。

## 一、语料与分词说明（量规 25%）

### 1.1 语料来源与控制变量

| 项目 | 说明 |
| --- | --- |
| 数据来源 | GitHub 仓库 Lars-0317/chinse-poetry「全唐诗」58 个 JSON 分片，共 57,607 首；字段 author / paragraphs / title / id；原文为繁体 |
| 作者与时期 | 王维（繁体作「王維」）、孟浩然；同为盛唐、同属山水田园诗派代表 |
| 体裁控制 | 仅取五言八句体（下称五言律诗）：8 句 × 5 字 = 40 汉字，句数与字数完全一致（全库命中 14,574 首）；按形式判定，未校验平仄对仗 |
| 样本量 | 王维 80 篇 / 孟浩然 80 篇；各自候选池 129 / 154 篇，按正文去重后无重复 |
| 抽样方式 | 固定随机种子 20261112，从各自候选池等篇数随机抽取；另用全部 283 篇做复核 |
| 繁简处理 | 分析前用 zhconv 统一转简体；繁体原句完整保留，供原文核查逐句回查 |
| 可复核文件 | 语料清单.csv（含 160 篇繁体全文、诗题、原始 ID）；data/tang/ 下 58 个原始 JSON |

控制思路：把「时期、流派、体裁、篇幅、样本量」尽量固定，让可能显现的差异更接近用词层面的差别，而不是由李白式古体长篇与律诗短章的长度差造成。两位作者候选池篇数不等（129 / 154），故先等篇数抽样，再用全部 283 篇复核。**体裁为操作性定义**：仅按「8 句 × 每句 5 字」形式判定，未校验平仄与对仗，故样本含少量乐府题与五言古体（如《相和歌辭 從軍行》）；这是可复核的筛选规则，也是本研究的局限之一。

### 1.2 统一预处理流程（两位作者完全一致）

1. 按标点把每首拆成 8 个五字句，保留繁体原句与简体句的一一对应关系；
2. 繁 → 简（zhconv 1.4.1），仅用于分析，原文核查仍引用繁体；
3. jieba 精确模式分词，加载作者无关的「唐诗通用二字词表」（300 条，数据驱动）；
4. 对 ≥3 字片断按五言 2+2+1 音步补切；仅保留 1–2 字词；
5. 按固定停用词表逐词精确过滤，得到每篇约 14 个二字词；
6. 所有篇目拼成以空格分隔的文档，交给同一个 TfidfVectorizer。

**为什么加领域词典：**jieba 用的是现代汉语词典，直接切古汉语会产出「清泉石 / 上流」「黃雲斷 / 春色」这类误切。领域词典从**全库 14,574 首五律**的句内二字组按文档频次生成，不含作者标签，对两组一视同仁；再加音步补切，把「絕域陽關道」切成「绝域 / 阳关 / 道」。分词对照示例见附录 D。

> **已记录的预处理风险：**① 繁简转换会合并同形异义字，样本中《歲暮海上作》「仲尼既云歿」的「云」（作「曰」解）与「雲」（云彩）在简体中都写作「云」；② 音步补切仍会产生伪词，如「葡萄逐漢臣」被切成「逐汉」，「當令外國懼」被合成「当令」。前者仅出现 1 篇、已被 min_df=2 过滤，后者进入词表但在抽查中被标为「分词存疑」。

## 二、分析设置与结果正确性（量规 30%）

| 设置项 | 取值 / 做法 |
| --- | --- |
| 分词器 | jieba 0.42.1 精确模式，两位作者使用完全相同的规则 |
| 领域词典 | 唐诗通用二字词表.txt：由全唐诗 14,574 首五律的句内二字组按文档频次取前 300 生成，作者无关、不含两位作者标签 |
| 音步补切 | jieba 未能切开的 ≥3 字片断，按五言 2+2+1 音步补切为 1–2 字词（例：陽關道 → 阳关 / 道） |
| 分析单位 | 主分析只保留二字词；古汉语单字兼类严重（「空」「日」等），单字结果另列稳健性对照 |
| 停用词 | 停用词表.txt，共 183 条，逐词精确匹配；含古汉语虚词、代词、方位词与功能性二字短语；两组共用 |
| 向量化 | sklearn TfidfVectorizer；analyzer=按空格切分已分词文本；lowercase=False |
| 阈值与权重 | min_df=2，max_df=0.90，sublinear_tf=True，use_idf=True，smooth_idf=True，norm='l2' |
| 拟合方式 | 两作者 160 篇合并后一次性 fit_transform，得到统一词表（200 词）与统一 IDF；再按作者分组求篇均权重 |
| 比较量 | mean_a(w) = (1 / \|D_a\|) · Σ tfidf(d, w)；差值 = mean_王维 − mean_孟浩然 |

**关键正确性说明：**没有对两位作者分别 fit。若各自拟合，IDF 会随各自语料变化，权重就不可直接相减。本分析在 160 篇合并语料上一次性 fit，共享同一词表与 IDF，之后仅按作者分组求篇均值。另外，**TF-IDF 权重不等于使用频率**：例如「白云」在王维 6 篇、孟浩然 2 篇中出现，「故人」在王维 4 篇、孟浩然 8 篇中出现，权重同时受词频、IDF 与 l2 归一化影响。完整词表见附录 A。

### 2.1 稳健性设计

另跑 5 组对照：保留单字、jieba 默认词典、字符 1–2 gram、改用全部 283 篇五律、放宽 min_df/max_df。结果见图 4：换设置后 Top15 差异词的 Jaccard 重合度为 0.15～0.88，**词表排序对设置敏感**；但「王维偏远景 / 送别，孟浩然偏交游 / 归隐」的语义方向在五组设置下都未反转。这一点直接限制了第五节结论的措辞强度。

## 四、回到原文的核查（量规 25%）

**抽查方法：**取两位作者各自 Top8 高权重词与 5 个高差值词，在各自 80 篇样本中检索简体句，再逐句回查繁体原文（并用 zhconv 做繁体回转换校验）；每词最多列 2 条例句，共 19 条记录。除「支持」外，*刻意*纳入反例、题材限定、用典集中、分词存疑与繁简合并五类情况。

> **核查得到的三点修正：**① **高权重≠独有**：「白云」「落日」「故人」「征帆」在两组都出现，差别是篇数与权重；② **高权重≠主题**：「愚公」三例全属「愚公谷」同一用典簇，「五色」三例分指五色瓜、五色分、凤雏，「遥知」「日夕」是句式/时间词；③ **题材会误导**：王维样本含《送劉司直赴安西》《使至塞上》等边塞送别作，「心悲」三例都在送别或挽歌，不能概括为「王维多悲」或「王维只写隐逸」。

## 五、约 150 字的解释（量规 20%）

> 在这 160 首盛唐五言律诗中，王维高权重词偏向远景（白云、落日、云外），孟浩然偏向交游与归乡（故人、乡园、征帆）。差异能支持：统一分词、停用词与同一 IDF 词表下，两组用词分布确不相同，且多数词能落回原句，可作细读线索。不能证明：这是二人整体风格或个性心理的定论，也不能推出题材成因、时代因果或作品高下；TF-IDF 权重不等于词频，换分词方案或样本后 Top15 重合度仅 0.11～0.88，结论对设置敏感。

| 比较维度 | 先秦典籍植物知识挖掘与组织 | ChatGPT 零样本临床量表抽取 |
| --- | --- | --- |
| 回答的问题 | 先秦典籍中有哪些植物实体？如何把这些实体及其关联知识组织成可检索、可关联的知识体系？ | 无标注条件下，能否按预定义框架把自由文本中的量表项目字段化？哪些属性、哪些文本条件下可行？ |

> **为什么不能把两文结果当成同一任务的直接优劣比较：**两文虽然都在做「从文本里把知识抽出来」，但对象（古汉语典籍 / 现代量表文档）、任务（开放领域的实体识别＋知识组织 / 固定 8 类属性的槽位填充）、路线（人工标注＋监督模型选优 / 无标注＋提示设计）、产出（NER 模型与知识图谱 / 分属性抽取结果与失效条件）、评价单位（实体级 F1 / 属性级 Micro-F1、Macro-F1）全都不同。因此「85.44% 小于 98.90%」不能推出「零样本提示优于古籍实体识别」，反过来也不能用前者的图谱能力否定后者；98.90% 与 45.51% 的落差本身就说明后者的成绩是*分属性、分条件*的，而非一个整体精度。要比较高下，必须在同一任务、同一语料、同一标注规范与同一评价指标下做对照实验。

**与本次作业的关系：**本文的 TF-IDF 是**无监督、语料级、探索性**的词汇权重描述，既不做实体识别，也不按 schema 抽字段；没有标注集、不算 F1、产不出知识图谱或结构化记录。它只能回答「在给定预处理下，哪组词在两组样本中权重更高」，属于远读线索；若要确认「典籍里有哪些植物实体」或「量表有哪些条目与计分规则」，就得走文献一或文献二那条路。三种方法不是同一任务的三个精度档次，而是三个不同的问题。
